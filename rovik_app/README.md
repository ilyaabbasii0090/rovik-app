# اپ اختصاصی VPN روویک — Rovik

کلاینت واقعی VPN برای اندروید (Flutter). موتور اتصال، هسته Xray/V2Ray
است (پلاگین `flutter_v2ray`)؛ با یک ضربه، ترافیک گوشی واقعاً از تونل
V2Ray عبور می‌کند. اپ فروشگاهی نیست؛ فروشگاه جدا در
`rovik_shop_app` است.

- نام اپ: **روویک** — پکیج: `com.rovikvpn.app` — نسخه: `1.0.0+1`
- فارسی و راست‌به‌چپ، تم تیره (سرمه‌ای + آبی نئون)

## امکانات

- **اتصال یک‌ضربه‌ای:** دکمه پاور مستقیم به کانفیگ انتخاب‌شده وصل
  می‌شود (بدون جست‌وجو و تست سرعت قبل از اتصال). سرعت دانلود/آپلود
  زنده و حجم کل، مستقیم از هسته V2Ray می‌آیند.
- **ایمپورت اشتراک با دیپ‌لینک:**
  - `rovik://import?sub=<url-encoded sublink>` (لینک «ورود به اپ
    اختصاصی روویک» در ربات تلگرام همین شکل را دارد)
  - `https://rovikvpn.shop/app/import?sub=<url-encoded>` (App Link)
- **لیست سرورها + پینگ واقعی:** پینگ با زمان اتصال TCP به
  هاست:پورت سرور اندازه‌گیری می‌شود؛ دکمه تازه‌سازی همه را دوباره
  تست می‌کند؛ «انتخاب خودکار بهترین سرور» کم‌پینگ‌ترین را انتخاب می‌کند.
- **بسته من:** حجم باقی‌مانده (گیگ) و روزهای باقی‌مانده با نوار پیشرفت،
  از `GET /api/app/sub-info?token=<token>`.
- **خرید / تمدید:** محصولات واقعی از `GET /api/shop/products`؛ شماره
  کارت با دکمه کپی؛ ثبت رسید با `POST /api/shop/receipt`.
- **فایل روویک (.rovik):** در تنظیمات می‌توان فایل JSON اشتراک را وارد
  کرد: `{"format":"rovik-subscription","version":1,"sub":"https://panel17.rovikvpn.shop/sub/<token>","name":"Rovik"}`.
- **آموزش اتصال:** پنج مرحله تصویری داخل اپ.
- **سیستم آپدیت:** در شروع، `GET /api/app/version` چک می‌شود؛ اگر
  نسخه جدیدتر باشد، دیالوگ مسدودکننده «باید آپدیت کنید» نمایش داده
  می‌شود و دکمه آپدیت، APK یا ربات تلگرام را باز می‌کند.
- **پشتیبانی:** باز کردن ربات تلگرام `t.me/RovikVpn_bot`.

## قراردادهای API (کد دقیقاً با همین‌ها نوشته شده)

| اندپوینت | پاسخ |
|---|---|
| `GET /api/app/sub-info?token=...` | `{"ok":true,"username":"...","used_gb":12.5,"total_gb":50.0,"days_left":25,"expires_at":"...","active":true}` |
| `GET /api/app/version` | `{"ok":true,"version":"1.0.0","min_version":"1.0.0","download_url":"https://rovikvpn.shop/dl/rovik.apk","force_update":false}` |
| `GET /api/shop/products` | لیست واقعی ۴ محصول فروشگاه |
| `POST /api/shop/order` + `POST /api/shop/receipt` | همان قرارداد `rovik_shop_api/app.py` |

> وضعیت در زمان ساخت (۲۰۲۶-۱۱-۲۰): `/api/shop/products` زنده و سالم
> است، اما `/api/app/sub-info` و `/api/app/version` هنوز روی سرور
> پیاده نشده‌اند (پاسخ HTML سایت برمی‌گردد). اپ دقیقاً با قرارداد
> بالا کد شده و وقتی اندپوینت‌ها زنده شوند، بدون تغییر کد کار می‌کند؛
> تا آن موقع، کارت بسته «—» نشان می‌دهد و دیالوگ آپدیت ظاهر نمی‌شود.

## ساخت APK

**روی ماشین معمولی یا GitHub Actions** (در سندباکس این محیط،
Gradle به‌خاطر مسدود بودن TCP جاوا ساخته نمی‌شود):

```bash
cd rovik_app
flutter pub get
flutter analyze        # باید ۰ خطا باشد
flutter test           # تست‌های پارس ساب‌لینک، پینگ، نسخه و فایل روویک
flutter build web      # خروجی وب برای پیش‌نمایش
flutter build apk --release
```

خروجی: `build/app/outputs/flutter-apk/app-release.apk`

GitHub Actions هم آماده است: `.github/workflows/build-apk.yml` — با
هر پوش به `main`، APK ریلیز را می‌سازد و به‌عنوان Artifact می‌دهد.

## iOS

iOS نیاز به macOS و Xcode دارد و پلاگین `flutter_v2ray` روی iOS
پیاده‌سازی ندارد (فقط اندروید). پس نسخه iOS فعلاً ساخته نمی‌شود.

## نکته مهم درباره سرعت

اپ خودش سرور را سریع‌تر نمی‌کند؛ سرعت به سرور و مسیر آن تا ایران
بستگی دارد. سرور آلمان (۵۱٫۸۹٫۱۱۲٫۱۰۷) با Shadowsocks در تست‌ها سریع
بوده است.
